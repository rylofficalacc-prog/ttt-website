# TTT Website — Phase 1

This Railway-ready Next.js site includes **only**:

- BrokeMace Kit
- OPManhunt
- BowBoostMace

## Upload to GitHub

1. Extract the ZIP.
2. Open your empty `ttt-website` GitHub repository.
3. Click **Add file → Upload files**.
4. Upload every file and folder from inside `ttt-website`. Do not upload only the ZIP.
5. Commit the files.

## Deploy to Railway

1. In Railway, click **Connect Repo**.
2. Select `ttt-website`.
3. Wait for the build.
4. Open **Settings → Networking → Generate Domain**.

## Run locally

```bash
npm install
npm run dev
```

Replace the `href="#"` Discord button in `app/page.js` with your invite.
